Цель: превратить локальную сборку в **публично доступную** систему, где любой человек может
зарегистрировать зону, проверить владельца и передать её — без вашей машины в цепочке.

Всё уже подготовлено в коде: добавлены сети `sepolia`/`mainnet`, переключение окружения,
автовыбор файла деплоя по сети, защита от деплоя «тестовым» ключом Hardhat в публичную сеть,
скрипты `deploy:sepolia`, `verify:sepolia`, `net:*`. Дальше нужны только ваши данные и аккаунты.

---

## Что значит «рабочий для всех» — три слоя

| Слой | Что даёт | Что нужно от вас |
| --- | --- | --- |
| **1. Контракт в публичной сети** | любой кошелёк может вызвать `registerTLD` с Etherscan или из нашего UI; состояние вечное, не у вас на диске | burner-кошелёк с тестовым ETH (Sepolia) |
| **2. Публичный сайт + API + indexer** | люди открывают ваш домен и регистрируют зоны через UI | хостинг (VPS или бесплатный PaaS) + Postgres |
| **3. Резолвер имён** (опционально) | `https://myzone.вашдомен` реально открывается в браузере | свой домен (≈$10/год) |

Слой 1 — самый важный: после него реестр уже **глобальный и не зависит от вашего компьютера**.
Слои 2 и 3 — это удобство доступа к нему.

## Шаг 0. Что прислать (минимум для слоя 1)

1. **Адрес владельца** — ваш обычный адрес из MetaMask (он станет `owner` контракта и админом).
2. **Приватный ключ burner-кошелька** — отдельный НОВЫЙ аккаунт в MetaMask, на котором
   только тестовые ETH для газа. Он платит за деплой и **не получает никаких прав**:
   владельцем сразу становится адрес из п.1, поэтому утечка ключа = потеря тестового газа, не более.
3. (Желательно) **Etherscan API key** — https://etherscan.io/myapikey → нужен, чтобы контракт был
   верифицирован и читался в обозревателе. Без него деплой всё равно пройдёт, верификация — позже.
4. **RPC URL** — не обязателен: по умолчанию берётся публичный `https://ethereum-sepolia-rpc.publicnode.com`
   (уже проверен из моего окружения: chainId 11155111, блок 12 189 690).

Присылать лучше так: я создам в воркспейсе файл `.env.secrets` (он в `.gitignore`, не попадает
в снапшоты проекта), вы вставите значения туда — и они не окажутся в переписке.

**Никогда** не присылайте ключ от кошелька, где лежат реальные деньги. Только свежий burner.

## Шаг 1. Получить тестовые ETH (Sepolia) — 5 минут

Любой из кранов (нужно ≈0.05 ETH на деплой + 3 транзакции настройки списков):

- https://cloud.google.com/application/web3/faucet/ethereum/sepolia — 0.05 ETH/сутки (нужен Google-аккаунт)
- https://www.alchemy.com/faucets/ethereum-sepolia — 0.5 ETH/сутки (нужен аккаунт Alchemy)
- https://faucet.quicknode.com/ethereum/sepolia
- https://sepolia-faucet.pk910.de — proof-of-work, без регистрации (медленнее, но без аккаунтов)

Проверить баланс: `https://sepolia.etherscan.io/address/<адрес burner>`.

## Шаг 2. Деплой контракта (делаю я)

Как только данные на месте, я выполняю:

```bash
# .env: SEPOLIA_RPC_URL, DEPLOYER_PRIVATE_KEY (burner), ADMIN_ADDRESS (ваш), ETHERSCAN_API_KEY
npm run deploy:sepolia      # пишет deployments/sepolia.json
npm run verify:sepolia -- <address> <owner> true   # верификация в Etherscan
npm run net:sepolia         # переключает приложение и indexer на Sepolia
```

Результат, который вы получите:

```
Contract: 0x…   (кликабельная ссылка sepolia.etherscan.io)
Owner:    0x…   (ваш адрес)
Первый блок: …
Gas:      ~200 000 (≈0.0004 ETH по тестовому газу)
```

Верификация даёт кнопки «Write contract» / «Read contract» в Etherscan: любой человек сможет
зарегистрировать зону **без нашего сайта** — это и есть «работает для всех».

Сам деплой можно сделать и у вас (если не хотите передавать ключ):

```bash
cd justtld
npm ci
# .env: SEPOLIA_RPC_URL, DEPLOYER_PRIVATE_KEY, ADMIN_ADDRESS, ETHERSCAN_API_KEY
npm run deploy:sepolia
npm run verify:sepolia -- <address> <owner> true
```

и прислать мне `deployments/sepolia.json` — этого достаточно, чтобы я продолжил.

## Шаг 3. Публичный сайт + API + indexer (нужен ваш выбор хостинга)

Три варианта, все проверяемы:

**Вариант A — свой VPS/сервер (проще всего, полный контроль).**
Ubuntu-сервер, домен, 2 ГБ RAM; я даю скрипт установки: Node 20, PostgreSQL, systemd-юниты
`justtld-web`, `justtld-indexer`, nginx + Let's Encrypt. ~30 минут, дальше `npm run start:all`
работает как локально, но на вашем домене.

**Вариант B — бесплатный PaaS (Render / Railway / Fly.io) + Neon Postgres.**
Нужны аккаунты; я подготовлю: Dockerfile или `render.yaml`, переменные окружения,
миграции при старте, health-check `/api/health`, отдельный воркер для indexer'а.

**Вариант C — без базы вообще (chain-only).**
Приложение читает зоны и историю напрямую из публичного RPC (`eth_getLogs`), Postgres не нужен →
сайт можно хостить где угодно статически + serverless-функции. Это доработка кода (~1 день):
кэш в памяти + пагинация по логам. Плюс: нулевая инфраструктура. Минус: поиск/фильтры медленнее
на большом объёме зон.

## Шаг 4. Домен для имён (опционально, слой 3)

Чтобы `myzone.вашдомен` открывался в браузере, нужен:
домен + wildcard-DNS `*.вашдомен` + TLS (сертификат на wildcard) + шлюз, который берёт
`metadata`/`contenthash` зоны и отдаёт контент (IPFS/Arweave/HTTP). Скажете «делаем» —
добавлю маршрут `/s/[tld]` и генератор конфигурации nginx.

## Шаг 5. Перед «настоящим» запуском (mainnet)

То, что нельзя пропустить, если зоны станут ценными:

- `Ownable` → `Ownable2Step` + мультисиг (Safe) как владелец: сейчас один ключ может
  заблокировать любую зону и поставить контракт на паузу;
- цены/аукционы: при бесплатной регистрации короткие имена скупит первый желающий;
- публичная политика `allowReclaim` (перехват истёкших имён);
- внешний аудит контракта и bug-bounty.

## Что уже готово в коде под публичную сеть

- `contracts/hardhat.config.ts` — сети `sepolia` (chainId 11155111) и `mainnet`, ключ деплоера только из env,
  `etherscan` для верификации.
- `npm run deploy:sepolia` / `deploy:mainnet` — пишут `deployments/<network>.json`.
- Защита: скрипт деплоя **отказывается** работать в публичной сети, если владелец или деплоер —
  публичный тестовый аккаунт Hardhat.
- `ADMIN_ADDRESS` при деплое задаёт `initialOwner` — владельцем сразу становится ваш адрес/мультисиг.
- `npm run net:localhost|sepolia|mainnet|status` — переключение приложения и indexer'а (меняет только
  безопасные ключи `.env`, комментарии сохраняются, приватные ключи не печатаются).
- Автовыбор файла деплоя: `DEPLOYMENT_NETWORK` → `CHAIN_ID` → `localhost` — один код для всех сетей.
- Dev Wallet автоматически отключается вне chainId 31337 (на публичной сети подпись только из MetaMask).
- Indexer: для публичной сети `INDEXER_CONFIRMATIONS=3`, `INDEXER_POLL_INTERVAL_MS=3000` (ставится
  автоматически командой `net:sepolia`).
- Проверено, что из окружения доступен публичный RPC Sepolia (`eth_chainId` = 0xaa36a7).
